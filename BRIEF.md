# Explore Illinois — practice build

Five standalone pages: index.html, springfield.html, chicago.html, peoria.html, contact.html. Shared styles.css and script.js. Local original SVG illustrations under assets/. No framework, backend, tracking, or build step.

Implement the Task 1 header, nav, main section with right aside, and footer. All pages link to all five pages and have one h1, a document title, an image with descriptive alt, and source references. Navy and rust palette, Arial body and Georgia headings, generous gaps, two columns on desktop and one on mobile.

Home introduces Illinois, links to the three cities, includes an ordered three-stop itinerary and three-row/four-column data table. Each city has population (2020 Census), incorporation year, geographic region, urban classification, and per-capita income compared with Illinois (2020–2024 ACS, 2024 dollars). Population totals deliberately use the same census date. Classification is an editorial description based on Census density, not a formal designation.

Contact fields: first-name, last-name, email, confirm-email, question. Required, explicitly labeled. Submit displays an alert on differing emails. Matching values show an honest local confirmation; no data is sent or stored. Noscript explains that JavaScript is required for this exercise. The form controls start disabled and are enabled by the script, preventing accidental submission without JavaScript.

Required CSS: body element selector, .city-card used three times, #contact-form id selector; nav hover, .state-image floated left; .image-label positioned absolutely over a relative .scene; .site-mark relative top 2px. These are purposeful, visible examples of the rubric rules.

Task 1 has passed the internal rubric check only. User's “keep going” authorizes continuing as practice; no instructor pass is claimed. Original wireframes remain under task-1; updated wireframes and explanation will accompany this build. Public hosting and official submission status are recorded separately in SUBMISSION.md.
